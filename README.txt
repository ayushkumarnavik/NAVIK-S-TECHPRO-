4. HOW TO OPEN THE WEBSITE
--------------------------

STEP 1:
Create a folder named NAVIKS-TECHPRO.

STEP 2:
Save the HTML, CSS, and SQL files using the exact
filenames listed above.

STEP 3:
Create an "images" folder inside the main folder.

STEP 4:
Place your six project images inside that folder.
Keep their filenames exactly as listed above.

STEP 5:
Open index.html in a browser to preview the website.

IMPORTANT:
The browser preview does not require a database to
display static HTML pages.


5. DATABASE SETUP
-----------------

The schema.sql file uses PostgreSQL.

To use it, you need a PostgreSQL database or a hosted
PostgreSQL service.

Review the schema and security settings before running
it in a real environment.

The SQL file creates the database tables only.
It does not connect the HTML forms to the database.


6. SECURITY REQUIREMENTS
------------------------

Before accepting real customer information:

- Configure secure server-side authentication.
- Protect administrator routes and customer records.
- Never publish database passwords or privileged keys.
- Store uploaded files in private storage.
- Validate file types, file sizes, and file contents.
- Use HTTPS on the deployed website.
- Configure database access policies and backups.
- Provide a real method for handling privacy requests.
- Test all security controls before launch.

The admin page is currently a visual interface.
It does not provide secure authentication by itself.

The order form does not persist submissions by itself.
